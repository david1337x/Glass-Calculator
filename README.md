# Premium Calculator

A visually stunning calculator app built with React, Tailwind CSS, and Framer Motion.

## Quick Start

1. Install dependencies:
   ```
   pnpm install
   ```

2. Start the dev server:
   ```
   pnpm run dev
   ```

3. Open http://localhost:5173 in your browser

## Features
- Dark / Light theme toggle
- Calculation history (saved in localStorage)
- Keyboard support
- Sound effects (mutable)
- Framer Motion animations
